# Media społecznościowe

Skorzystaj z tych szablonów w języku polskim, aby napisać wiadomość, post lub komentarz. Wybierz temat i odbiorcę poniżej, uzupełnij pola konta i miejsca, a potem dodaj osobistą uwagę; wiadomości prywatne podpisz swoim imieniem. „Lokalny” oznacza twój własny kraj — skontaktuj się z jego mediami, instytucjami lub posłami. Dla dłuższych wiadomości z danymi i odniesieniami skorzystaj z [listów](../messages/index.md).

| Odbiorca | Cel |
| --- | --- |
| Lokalne media | Zbadać, zweryfikować i poinformować lokalną opinię publiczną. |
| Lokalna instytucja | Wykorzystać kanały dyplomatyczne lub monitorujące, by domagać się gwarancji i działań następczych. |
| Poseł krajowy | Zapytać własny rząd i domagać się krajowej kontroli parlamentarnej. |
| Poseł do PE | Zapytać Komisję i przyjrzeć się postępom w procesie akcesyjnym oraz działaniom UE. |
