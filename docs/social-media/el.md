# Μέσα κοινωνικής δικτύωσης

Χρησιμοποιήστε αυτά τα πρότυπα στα ελληνικά για ένα μήνυμα, μια ανάρτηση ή ένα σχόλιο. Επιλέξτε ένα θέμα και έναν αποδέκτη παρακάτω, συμπληρώστε τα πεδία λογαριασμού και τοποθεσίας, και προσθέστε μια προσωπική πρόταση· υπογράψτε τα ιδιωτικά μηνύματα με το όνομά σας. Το «Τοπικό» σημαίνει τη δική σας χώρα — επικοινωνήστε με τα μέσα ενημέρωσης, τους φορείς ή τους βουλευτές της. Για μεγαλύτερα μηνύματα με στοιχεία και αναφορές, χρησιμοποιήστε τις [επιστολές](../messages/index.md).

| Αποδέκτης | Στόχος |
| --- | --- |
| Τοπικά μέσα ενημέρωσης | Διερεύνηση, επαλήθευση και ενημέρωση του τοπικού κοινού. |
| Τοπικός φορέας | Χρήση διπλωματικών ή εποπτικών διαύλων για να ζητηθούν εγγυήσεις και παρακολούθηση. |
| Τοπικός βουλευτής | Να ερωτηθεί η δική του κυβέρνηση και να ζητηθεί εθνικός κοινοβουλευτικός έλεγχος. |
| Ευρωβουλευτής | Να ερωτηθεί η Επιτροπή και να εξεταστεί η πρόοδος ένταξης και η δράση της ΕΕ. |
