# Соціальні мережі

Використовуйте ці шаблони українською для повідомлення, публікації або коментаря. Оберіть тему та отримувача нижче, заповніть поля облікового запису та місця, додайте особисте речення; підписуйте приватні повідомлення своїм іменем. «Місцевий» означає вашу власну країну — зверніться до її медіа, установ або депутатів там. Для довших повідомлень із цифрами та посиланнями користуйтеся [листами](../messages/index.md).

| Отримувач | Мета |
| --- | --- |
| Місцеві медіа | Розслідувати, перевіряти та висвітлювати для місцевої аудиторії. |
| Місцева установа | Використати дипломатичні або моніторингові канали, щоб вимагати гарантій і подальших дій. |
| Народний депутат | Вимагати відповідальності від власного уряду та національного парламентського контролю. |
| Євродепутат | Вимагати відповідальності від Комісії та стежити за прогресом вступу й діями ЄС. |
