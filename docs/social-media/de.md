# Soziale Medien

Verwenden Sie diese deutschen Vorlagen für eine Nachricht, einen Beitrag oder einen Kommentar. Wählen Sie unten ein Thema und einen Empfänger aus, füllen Sie die Platzhalter für Konto und Ort aus und fügen Sie einen persönlichen Satz hinzu; unterschreiben Sie private Nachrichten mit Ihrem Namen. „Lokal" bedeutet Ihr eigenes Land — kontaktieren Sie dessen Medien, Institutionen oder Abgeordnete dort. Für längere Nachrichten mit Zahlen und Quellen verwenden Sie die [Briefe](../messages/index.md).

| Empfänger | Ziel |
| --- | --- |
| Lokale Medien | Recherchieren, verifizieren und für das lokale Publikum berichten. |
| Lokale Institution | Diplomatische oder Überwachungskanäle nutzen, um Garantien und Folgemaßnahmen zu fordern. |
| Nationaler Abgeordneter | Die eigene Regierung befragen und eine nationale parlamentarische Kontrolle fordern. |
| EU-Abgeordneter | Die Kommission befragen und den Beitrittsprozess sowie das EU-Handeln prüfen. |
