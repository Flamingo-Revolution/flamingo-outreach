# Rețele sociale

Folosiți aceste șabloane în limba română pentru un mesaj, o postare sau un comentariu. Alegeți un subiect și un destinatar mai jos, completați câmpurile pentru cont și locație și adăugați o propoziție personală; semnați mesajele private cu numele dvs. „Local” înseamnă propria țară — contactați mass-media, instituțiile sau parlamentarii săi. Pentru mesaje mai lungi cu cifre și referințe, folosiți [scrisorile](../messages/index.md).

| Destinatar | Obiectiv |
| --- | --- |
| Mass-media locală | Investighează, verifică și informează publicul local. |
| Instituție locală | Folosește canale diplomatice sau de monitorizare pentru a cere garanții și urmărire. |
| Parlamentar național | Interpelează propriul guvern și cere control parlamentar național. |
| Europarlamentar | Interpelează Comisia și analizează progresul procesului de adeziune și acțiunea UE. |
