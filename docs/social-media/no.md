# Sosiale medier

Bruk disse malene på norsk til en melding, et innlegg eller en kommentar. Velg et tema og en mottaker nedenfor, fyll ut konto- og stedsfeltene, og legg til en personlig setning; signer private meldinger med navnet ditt. «Lokal» betyr ditt eget land — kontakt mediene, institusjonene eller stortingsrepresentantene der. For lengre meldinger med tall og referanser, bruk [brevene](../messages/index.md).

| Mottaker | Mål |
| --- | --- |
| Lokale medier | Undersøke, verifisere og rapportere for lokalt publikum. |
| Lokal institusjon | Bruke diplomatiske kanaler eller overvåkingskanaler for å be om garantier og oppfølging. |
| Nasjonal folkevalgt | Stille sin egen regjering spørsmål og be om nasjonal parlamentarisk kontroll. |
| EU-parlamentariker | Stille spørsmål til Kommisjonen og granske fremdrift i tilslutningsprosessen og EUs handling. |
