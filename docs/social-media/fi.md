# Sosiaalinen media

Käytä näitä suomenkielisiä malleja viestiin, julkaisuun tai kommenttiin. Valitse aihe ja vastaanottaja alta, täytä tili- ja paikkakohdat ja lisää henkilökohtainen lause; allekirjoita yksityiset viestit nimelläsi. "Paikallinen" tarkoittaa omaa maatasi — ota yhteyttä sen tiedotusvälineisiin, instituutioihin tai kansanedustajiin. Pidempiin viesteihin, joissa on lukuja ja lähteitä, käytä [kirjeitä](../messages/index.md).

| Vastaanottaja | Tavoite |
| --- | --- |
| Paikallismedia | Tutkia, varmistaa ja uutisoida paikalliselle yleisölle. |
| Paikallinen instituutio | Käyttää diplomaattisia tai valvontakanavia takeiden ja seurannan pyytämiseksi. |
| Kansanedustaja | Kysyä omalta hallitukselta ja vaatia kansallista parlamentaarista valvontaa. |
| Europarlamentaarikko | Kysyä komissiolta ja tarkastella liittymisprosessin edistymistä ja EU:n toimia. |
