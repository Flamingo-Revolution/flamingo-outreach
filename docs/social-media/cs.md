# Sociální média

Použijte tyto šablony v češtině pro zprávu, příspěvek nebo komentář. Vyberte téma a adresáta níže, vyplňte údaje o účtu a místě a doplňte osobní větu; soukromé zprávy podepište svým jménem. „Místní“ znamená vaši vlastní zemi — kontaktujte její média, instituce nebo poslance. Pro delší zprávy s čísly a odkazy použijte [dopisy](../messages/index.md).

| Adresát | Cíl |
| --- | --- |
| Místní média | Vyšetřit, ověřit a informovat místní veřejnost. |
| Místní instituce | Využít diplomatické nebo monitorovací kanály k vyžádání záruk a navazujících kroků. |
| Poslanec parlamentu | Zpochybnit vlastní vládu a požadovat vnitrostátní parlamentní dohled. |
| Europoslanec | Zpochybnit Komisi a prověřit pokrok v přístupovém procesu a kroky EU. |
