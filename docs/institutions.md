## Download the data

[Download the CSV](assets/data/institutions.csv) or [update the shared workbook](https://docs.google.com/spreadsheets/d/19qp5A7qB5DwoKEF6WlYKy_GSWNOxTgMX/edit?usp=sharing). This is a snapshot, so responses may change between checks.

**Read the status:** Done means a response link is recorded. Todo means there is no response link in this tracker; it does not establish whether an organization was contacted or responded elsewhere. A linked response does not imply support.
