## How to record contributions

Add a column called **Contributors** to each Excel worksheet. Enter a consistent public name or handle for the person who added or maintained that row. Separate multiple names with semicolons, for example `Alex; Sam`. The column can appear anywhere in the sheet. It is separate from the institutions' **Contribution** column, which describes an organization's activity.

Each named person receives one credit per nonempty data row. A name repeated in one cell counts once; capitalization and extra whitespace are ignored when matching names. Shared rows credit every named person once. Blank Contributors cells receive no credit. Totals cover every worksheet exported from the workbook, including example and evidence sheets; identical records entered in different sheets each count as a row in their own sheet.

Counts measure attributed rows, not edits, hours, quality, or impact. Updating a row does not add another credit. The ranking updates when the workbook data import runs; existing rows remain unattributed until someone supplies names. Only enter names or handles people agree to have displayed publicly.
